# Jewellery Store 💎

An online jewellery shopping application developed using Java Spring Boot.

## About the Project
Jewellery Store is an e-commerce web application designed to provide users with a simple online jewellery shopping experience.

## Features
- Browse jewellery products
- View product details
- Add products to cart
- Manage shopping cart
- Place orders
- Checkout functionality

## Technologies Used
- Java
- Spring Boot
- HTML
- CSS
- JavaScript
- Maven

## Project Structure
- `src/main/java` – Backend Java application
- `src/main/resources/static` – Frontend files
- `pom.xml` – Maven dependencies and configuration

## How to Run
1. Clone this repository.
2. Open the project in VS Code or IntelliJ IDEA.
3. Run the Spring Boot application.
4. Open `http://localhost:8080` in your browser.
